# Contributing

Thank you for helping improve AARD Visual Director.

## What makes a useful contribution?

- More original concept-development methods.
- Clearer prompt-writing guidance.
- Better workflows for reference images and visual continuity.
- Examples that demonstrate genuinely different creative directions.
- Corrections that improve portability across compatible Agent Skills hosts.

## Contribution guidelines

1. Open an issue before making a large or structural change.
2. Keep instructions platform-independent unless a platform-specific guide is clearly labeled.
3. Do not add claims that a prompt can guarantee exact identity, perfect realism, or identical results across models.
4. Keep examples self-contained and avoid including private reference images or personal data.
5. Explain the problem a change solves.
6. Keep the core `SKILL.md` focused; put long supporting material in `references/`.

## Pull request checklist

- [ ] The change improves usefulness, clarity, creativity, or compatibility.
- [ ] User constraints and safety boundaries remain clear.
- [ ] No unsupported platform capabilities are claimed.
- [ ] Examples are original and do not rely on copyrighted character or artist imitation.
